# HH Employment API Interaction
## Описание проекта
HH Employment API Interaction — это приложение, предназначенное для взаимодействия с API HeadHunter (hh.ru). Оно позволяет пользователям получать информацию о вакансиях, создавать списки поиска и управлять вакансиями. Проект разработан на языке Python с использованием объектно-ориентированного программирования и модульной структуры кода.

## Установка
Для начала работы с данным проектом выполните следующие шаги:

Клонируйте репозиторий:
```bash 
git clone https://github.com/Evratal/Course_work_hh_bd.git cd Course_work_hh_bd
```
Создайте и активируйте виртуальное окружение:
На Windows:
```bash 
python -m venv venv venv\Scripts\activate
```
На macOS/Linux:
```bash
 python3 -m venv venv source venv/bin/activate
 ```

Установите зависимости: Убедитесь, что у вас установлен pip, и выполните:
```bash
 pip install -r requirements.txt
 ``` 
Убедитесь, что в вашем requirements.txt указаны все необходимые библиотеки для работы с проектом, такие как requests, flask (если используется) и другие.
Настройка конфигурации

## Для работы с базой данных необходимо настроить файл конфигурации config.ini. Измините файл config.ini в корневой директории проекта и добавьте следующие строки:

[database]
host = localhost
database = ....
user = ....
password = ....
Объяснение полей:

host: Адрес сервера базы данных (обычно localhost для локального подключения).
database: Имя базы данных, с которой будет производиться работа.
user: Имя пользователя для подключения к базе данных.
password: Пароль для пользователя базы данных.
Использование
Запуск приложения
Для запуска приложения выполните команду: bash python main.py Приложение подключится к API HeadHunter и откроет интерфейс для взаимодействия с пользователем.

## Интерфейс пользователя
Программа предоставляет интерактивный интерфейс, который позволяет пользователям:

Искать вакансии
Фильтровать результаты
Просматривать информацию о конкретных вакансиях
Примечания
Убедитесь, что у вас есть доступ к API HeadHunter, и вы ознакомлены с их документацией для понимания всех возможных параметров и ограничений по запросам.

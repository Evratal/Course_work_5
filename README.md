# HH Employment API Interaction

## Описание проекта

HH Employment API Interaction — это приложение, предназначенное для взаимодействия с API HeadHunter (hh.ru), которое позволяет пользователям получать информацию о вакансиях, создавать списки поиска и управлять вакансиями. Проект разработан на языке Python с использованием объектно-ориентированного программирования и модульной структуры кода.

## Установка

Для начала работы с данным проектом выполните следующие шаги:

1. **Клонируйте репозиторий**:
```bash
   git clone https://github.com/Evratal/Course_work_hh_bd.git
   ```
   cd hh_employment_api
2. Создайте и активируйте виртуальное окружение:
На Windows:
```
   python -m venv venv
   venv\Scripts\activate
```
На macOS/Linux:
```
   python3 -m venv venv
   source venv/bin/activate
 ```
3. Установите зависимости:Убедитесь, что у вас установлен pip, и выполните:
```
   pip install -r requirements.txt
```
4. Убедитесь, что в вашем requirements.txt указаны все необходимые библиотеки для работы с проектом, такие как requests, 
flask (если используется) и другие.

Использование
Запуск приложения:Для запуска приложения выполните команду:
```
   python main.py
```
Приложение подключится к API HeadHunter и откроет интерфейс для взаимодействия с пользователем.

Интерфейс пользователя:Программа предоставляет интерактивный интерфейс, который позволяет пользователям искать вакансии, 
фильтровать результаты и просматривать информацию о конкретных вакансиях.
